# Лабораторная работа №1: Защита данных с помощью AES-256

---

## 📋 Постановка задачи

Реализовать защиту данных пользовательских папок и файлов, находящихся в папке, а также подпапках путем шифрования. Для доступа к данным исходной папке необходимо выполнить дешифрование.

- 1 Интерфейс приложения - консоль
- 2 В качестве основной библиотеки для реализации шифрования можно взять библиотеку Crypto++ Library, либо Aes256
   - https://codezup.com/cryptography-security-in-cpp-applications/
   - https://codezup.com/cpp-aes-256-encryption-implementation/
- 3 Потребуется реализация рекурсивного обхода папок, с целью шифрования всех вложенных файлов. Для реализации этой задачи можно воспользоваться библиотеками Qt.Представляет богатый инструментарий по работе с директориями и файла.

- Можно рассмотреть пример, в котором рассмотрен обход дерева каталогов.
   - https://pro-prof.com/forums/topic/%D0%BE%D0%B1%D1%85%D0%BE%D0%B4-%D0%B4%D0%B5%D1%80%D0%B5%D0%B2%D0%B0-%D0%BA%D0%B0%D1%82%D0%B0%D0%BB%D0%BE%D0%B3%D0%BE%D0%B2-c-qt

### Требование к реализации
- 1 Язык с++
- 2 Реализовать основной класс, обеспечивающий шифрование(encryption), дешифрование (decryption) как Singleton.
- 3 Входные данные: путь к папке для шифрования/дешифрования, пароль для шифрования.

## 🔐 Выбор библиотек для шифрования

В качестве основной библиотеки для реализации шифрования используется **OpenSSL** с реализацией алгоритма **AES-256**.

| Библиотека | Описание |
|------------|----------|
| OpenSSL (EVP API) | Мощная криптографическая библиотека, реализующая AES-256 в режиме CBC |
| Qt Core | Кроссплатформенный фреймворк для работы с файловой системой, хэшированием и логированием |

## 📂 Работа с файловой системой

Для рекурсивного обхода папок и шифрования всех вложенных файлов используется библиотека **Qt**, которая предоставляет богатый инструментарий для работы с директориями и файлами (`QDir`, `QFileInfo`, `QFile`).

## 🏗 Архитектура приложения

### Основные сущности (классы)

| Класс/Структура | Назначение |
|-----------------|------------|
| `CryptoManager` | Синглтон, отвечающий за шифрование/дешифрование файлов с использованием AES-256. Содержит ключ и IV, полученные из пароля. |
| `Logger` | Синглтон для логирования операций в файлы с потокобезопасностью через `QMutex`. |
| `FileInfo` | Структура для хранения информации о файле: путь, относительный путь, размер, флаг `isEncrypted`. |
| `ProcessingResult` | Структура для сбора статистики обработки: всего файлов, успешно, пропущено, защищено, ошибок. |
| `OperationMode` | Enum для режимов работы: `Encrypt`, `Decrypt`, `None`. |
| `LogOperation` | Enum для различения операций при логировании пропущенных файлов. |

### Использованный паттерн: Singleton
Паттерн **Singleton** гарантирует, что у классов `CryptoManager` и `Logger` существует только один экземпляр на всё приложение. Это важно, потому что:
- ключи шифрования должны быть едины для всех операций;
- логи должны писаться в одни и те же файлы из любой точки программы.

## ⚙️ Требования к реализации

### 1. Архитектура приложения
- Реализован основной класс `CryptoManager`, обеспечивающий шифрование (encryption) и дешифрование (decryption)
- Класс реализован как **Singleton**
- Реализован класс `Logger` для ведения детальных логов операций (синглтон)

### 2. Входные данные
Приложение принимает на вход **три обязательных параметра**:

| Параметр | Описание | Пример |
|----------|----------|--------|
| **Путь к папке** | Полный или относительный путь к директории, содержимое которой будет обработано | `C:\Users\Документы\Secret` или `./test_folder` |
| **Пароль** | Строка для генерации ключа шифрования | `MySecurePassword123` |
| **Режим работы** | 1 — шифрование, 2 — дешифрование | `1` или `2` |

Все параметры вводятся пользователем последовательно в консоли.

### 3. Функциональность
- Рекурсивный обход всех подпапок через `collectFilesInfo`
- Проверка статуса файла (зашифрован/не зашифрован) по специальному маркеру `ENCRYPTED_MARKER` (8 байт: `0xEF 0xBE 0xAD 0xDE 0x01 0x02 0x03 0x04`)
- **Защита от повторного шифрования/дешифрования**: программа пропускает файлы, уже находящиеся в целевом состоянии
- **Защита системных файлов**: программа автоматически пропускает файлы с атрибутами `SYSTEM`, `HIDDEN`, `DEVICE`, а также файлы, недоступные для записи (метод `isProtectedSystemFile`)
- **Детальное логирование**: все операции записываются в отдельные файлы (`logs_encrypt.txt`, `logs_decrypt.txt`, `logs_errors.txt`, `logs_info.txt`) с временными метками
- **Подведение статистики**: после выполнения операции выводится количество успешно обработанных, пропущенных файлов (с детализацией по системным) и ошибок через структуру `ProcessingResult`

## 🔐 Программа для шифрования/дешифрования файлов (AES-256)

Данная программа предназначена для рекурсивного шифрования и дешифрования всех файлов в указанной папке с использованием алгоритма AES-256 (режим CBC). Программа написана на C++ с использованием Qt Core и OpenSSL.

## 📌 Реализованное решение

### Общая идея
Пользователь вводит:
- **полный путь к папке** для обработки;
- **пароль** (используется для генерации ключа AES-256 и вектора инициализации);
- **режим работы**: **1** — шифрование, **2** — дешифрование.

Программа:
1. Проверяет существование указанной папки.
2. Рекурсивно обходит все файлы внутри неё с помощью `collectFilesInfo`.
3. **В режиме шифрования:**
   - проверяет, не является ли файл системным или защищенным (такие файлы пропускаются с занесением в лог);
   - проверяет наличие маркера шифрования через `isFileEncrypted`; если файл уже зашифрован — пропускает его;
   - шифрует каждый файл алгоритмом AES-256 (CBC) через `processSingleFile`;
   - в начало каждого зашифрованного файла записывается специальный маркер (`ENCRYPTED_MARKER`) для идентификации зашифрованных файлов.
4. **В режиме дешифрования:**
   - проверяет, не является ли файл системным (пропускает);
   - проверяет наличие маркера с помощью `isFileEncrypted`;
   - дешифрует файлы, если они зашифрованы, через `processSingleFile`;
   - пропускает уже расшифрованные файлы.
5. По окончании работы выводит подробную статистику через `ProcessingResult` и сохраняет все действия в лог-файлы.

## 🔧 Используемые технологии

### 1. Qt Core (фреймворк)
**Суть технологии:**
Qt — кроссплатформенный фреймворк для разработки на C++. В программе используются модули `QCoreApplication`, `QFile`, `QDir`, `QFileInfo`, `QDateTime`, `QMutex`.

**Решаемые задачи:**
- Удобная работа с файловой системой (обход папок, проверка существования, получение относительных путей).
- Кроссплатформенное чтение/запись файлов.
- Потокобезопасное логирование с помощью `QMutex`.
- Формирование временных меток для логов.

### 2. OpenSSL (криптографическая библиотека)
**Суть технологии:**
OpenSSL — мощная библиотека, реализующая SSL/TLS и различные криптографические алгоритмы, включая AES.

**Решаемые задачи:**
- Генерация ключа (SHA-256) и IV (SHA-1) из пароля в `deriveKeyFromPassword`.
- Шифрование и дешифрование данных по алгоритму AES-256 в режиме CBC через `createCipherContext`.

**Использование EVP API:**
- `EVP_CIPHER_CTX_new()` — создание контекста.
- `EVP_EncryptInit_ex` / `EVP_DecryptInit_ex` — инициализация с ключом и IV.
- `EVP_EncryptUpdate` / `EVP_DecryptUpdate` — обработка блоков данных.
- `EVP_EncryptFinal_ex` / `EVP_DecryptFinal_ex` — финализация (добавление/удаление padding).

## 🔐 Безопасная разработка

### 1. Обработка пароля
- Пароль не хранится в открытом виде — из него сразу генерируется ключ и IV в `deriveKeyFromPassword`.
- Используется SHA-256 для ключа (32 байта) и SHA-1 для IV (обрезается до 16 байт).
- Ключ и IV хранятся в `unsigned char` массивах и обнуляются с помощью `secureZero` после использования (в деструкторе).
- Пароль в памяти затирается через `secureStringClear` сразу после генерации ключа.

### 2. Маркер зашифрованного файла
- В начало файла записывается уникальная сигнатура `ENCRYPTED_MARKER` (8 байт).
- Функция `isFileEncrypted` проверяет наличие этого маркера, что предотвращает повторное шифрование и позволяет быстро определить статус файла.

### 3. Защита системных файлов
- Функция `isProtectedSystemFile` проверяет атрибуты файла (Windows) и список защищенных имен (`.gitattributes`, `.gitignore`).
- Файлы с атрибутами `SYSTEM`, `HIDDEN`, `DEVICE`, а также скрытые файлы и файлы, недоступные для записи (через `isFileWritable`), автоматически пропускаются.

### 4. Логирование
- Все действия записываются в отдельные файлы: шифрование, дешифрование, ошибки, информация.
- Логи содержат временные метки и детализацию по каждому файлу.
- В конце каждой операции выводится итоговая статистика и записывается в лог.

### 5. Работа с памятью и файлами
- Буферы фиксированного размера (`BUFFER_SIZE` = 4096 байт) для чтения/записи.
- Временные файлы (`*.tmp`) создаются для безопасной обработки и удаляются в случае ошибки.
- Атомарность операций: при ошибке оригинальный файл не повреждается.

## ❓ Инструкция для пользователя

### Требования
- Windows 10 (x64)
- Qt 5.15.2 (MinGW_64)
- OpenSSL (разработанной версии Qt)

### Сборка и запуск
1. Откройте `CMakeLists.txt` и укажите путь к OpenSSL в переменной `OPENSSL_ROOT_DIR`.
2. Откройте проект в Qt Creator.
3. В настройках запуска включите "Запускать в терминале".
4. Нажмите `Запустить` или `Ctrl+R`.

### Как пользоваться
1. Введите **полный путь** к папке.
2. Введите пароль.
3. Введите `1` (шифрование) или `2` (дешифрование).

### Логирование
После выполнения в папке с программой появятся:
- `logs_encrypt.txt` — лог шифрования
- `logs_decrypt.txt` — лог дешифрования
- `logs_errors.txt` — лог ошибок
- `logs_info.txt` — информационные сообщения
